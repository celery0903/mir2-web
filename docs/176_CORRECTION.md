## 自写原型的历史修正

- 统一 800×600 逻辑画面，原 800×251 底栏固定在 y=349；浏览器整体等比适配，地图保持原始像素采样。透明装饰区域用原图的像素遮罩判断地图点击。
- 恢复 Prguse 第 3 帧的 336×270 背包，以及第 370 帧的 232×325 人物窗。F9/F10 独立控制；装备按原纸娃娃和饰品格显示。
- 六格快捷栏与 40 格背包分开。原网关错误地按收到顺序放置物品，导致装备占快捷格；现在依原客户端 `AddItemBag`，StdMode 0–3 优先进入前六格，其他物品从第七格开始。普通物品双击或选择后点击“使用”，数字 1–6 使用对应快捷格。
- NPC 对话用第 384 帧，商店用第 385 帧：三列、十行、13 像素行高、红色选中项、原翻页和确认按钮。选择、购买与详细商品子列表继续交给真实服务端处理。
- 战士低于 28 级显示单红球，其余显示分红蓝球；删除新增的地面选中环、移动标记及飘字伤害。右键两格跑步与 Shift+方向移动使用原生 Run 消息，障碍和结算仍由服务端决定。
- 登录窗使用第 60 帧及第 61 帧提交按钮，注册使用第 63 帧、双人物选角使用第 65 帧、建角使用第 73 帧。选中人物使用原 16 帧动画，未选中人物静止；三职业与男女性别使用原按钮。加入注册密码确认、原资料字段、取消和删除本人角色流程。尚未还原全部过场动画。
- 注册资料按 GB2312 编码后的原字段宽度验证，手机号码另受原账号库 11 位列宽限制。修复上游将电话和手机都写成生日的错误，补丁保留在 `server/openmir2-linux.patch`。
- 接入原生 `CM_USERSTORAGEITEM`、`CM_USERTAKEBACKSTORAGEITEM` 及对应回包。保管框使用第 392/393 帧，找回目录使用第 385 帧；支持点击选择与拖入保管框，收到服务端确认后才移除背包物品。空仓库列表也会返回，修复上游空列表不发回包和分页累计前页的问题。边界保管员位置来自固定候选的 `MerChant.txt`，来源、哈希和基础脚本见 `shared/classic-storage.json`；没有据此认证整份候选数据。
- 仓库入口触发格与门的图形格相邻，原自动开门只检查目标格导致无法进入。改为检查目标格周围九格，仍保留原门权限校验；真实角色行走已验证 `0 307,627 -> 0140 2,10`。
- NPC 朝向按原客户端 `TNpcActor.CalcActorFrame/GetDefaultFrame` 取模 3，修复朝向 3–7 时保管员消失。点击 NPC 直接发送原对话请求，不再寻路到柜台后的隔离格；角色点击增加精灵非透明像素检测，保留脚下格选择。
- 删除合成振荡器提示音，改用已有固定资源中的按钮、施法、受击、死亡及金币 WAV。未将未核对的完整音效/BGM 算作完成。
- 源码配置改用 `bichon-prototype` 标识，目标版本与 `fidelityStatus: incomplete` 分开记录。
