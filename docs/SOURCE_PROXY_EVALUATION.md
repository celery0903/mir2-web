日期：2026-10-04。目标版本仍为 2003 年盛大 1.76。用户指出网页客户端被重新实现后，停止扩大自写客户端，优先验证现成 H5 源码及其协议代理。

## 已经实测

候选为 [leiniaozl229/mir2](https://github.com/leiniaozl229/mir2/tree/77e3ff7506b1ca55cac15df247cb2fcedd69c535)，固定提交 `77e3ff7506b1ca55cac15df247cb2fcedd69c535`。`apps/web` 是 Pixi 浏览器客户端，`services/web-gateway` 是 .NET 10 WebSocket/传统 TCP 网关，两者已有对应协议。

使用其已有网关构建产物，以只读目录挂载运行；`services/web-gateway` 源码未修改。测试容器 `mir2-source-proxy` 只绑定 `127.0.0.1:18884`，接入 `mir2-rebuild_default` 网络内的隔离 OpenMir2 引擎。没有连接正式玩家库。

直接使用该项目的 WebSocket 消息完成新账号注册、登录、战士建角、进入比奇、权威能力和初始物品读取以及一格行走。初始物品为蜡烛、小量金创药、木剑和男布衣。移动 `289,616 -> 289,615` 获得服务端确认。结果见 [Proxy 证据](correction/source-proxy-evidence.json)。这证明复用该协议代理可行，尚不证明网页画面或全系统可用。
