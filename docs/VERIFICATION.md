## 验收数据

技能测试只将正则限定的 `qa` 测试角色离线提升到七级、20000 金币并调整生命和法力，随后通过真实商店买卖、购买技能书和使用。浏览器技能验收清除这些角色的已学技能后，再通过网页购买和学习。没有注入技能、书本、药水或掉落。

三职业功能的无凭据结果保存在 [功能证据](feature-evidence.json)。异常 TCP 分包回归直接访问测试栈的本机登录端口，并要求之后三职业仍能认证登录。

网页操作证据见 [浏览器功能证据](browser-feature-evidence.json)。所有游戏操作使用真实点击和方向键，WebSocket 观察器只读回包；NPC、怪物与玩家的类型误分类计数为 0。找怪测试沿途检查可见目标，处理移动怪物的坐标变化和窄路阻挡，不注入怪物、伤害或掉落。

已检查截图：[商店](shop.png)、[书店](bookshop.png)、[战斗掉落](combat.png)、[火球伤害](fireball.png)、[治愈动画](healing.png)。环境准备及完整复现命令见 [README](../README.md#验证)。

空库启动结果见 [首次启动证据](firstboot-evidence.json)。该临时栈及其测试卷已清理。

重启结果见 [重启证据](restart-evidence.json)。先分别重新登录三职业，核对原物品和技能完整并采集已结算的游戏状态，再让战士保持在线移动后停机。重启后的字段与这份紧邻停机的基线比较；浏览器战斗中的早期快照不会覆盖后续实际获得的经验。

正式容器与外部浏览器结果见 [部署证据](deployment-evidence.json)。旧 Crystal 容器、镜像和两个旧存档卷已删除。独立验收栈在完成检查后停止，保留验收卷；正式 18880 持续运行。

## 验收中修复

- 原生 TCP 分包、异常报文导致登录工作线程退出，以及 Linux 路径、编码和终端兼容问题。
- 地图墙体状态跨格泄漏、开门与移动执行顺序、门和地面物品缺少唯一 ID。
- 金币合并数量、归属和旧 ID 清理，以及多件可见掉落复用同一记录。
- 在线角色保存确认和原生进程正常退出。
- 网页背包识别类型 `4` 的技能书、目标死亡后停止追赶，以及商店商品图标匹配。
- 原生外观更新回包保持 NPC、玩家和怪物的实际类型。
- 监督进程提前结束原生停机等待，导致数据库连接过早关闭；等待引擎退出并将 Compose 宽限期设为 45 秒。
- MySQL 首次初始化的临时 socket 服务被错误判为就绪，改用 TCP 探测。

测试凭据和即时存档预期在 Git 忽略的 `.state/`；数据库随机密码在被忽略的 `.runtime/openmir2/database.env`。报告不包含这些凭据。

## 已知边界

- 当前开放范围是比奇与店铺；仓库、行会、攻沙、其他野外和洞穴、大部分技能未完成网页验收。
- 上游 SQL 和环境种子含混合版本数据，采用过滤后的经典地图、NPC、可显示怪物和经验配置；不能据此宣称数值与完整国服 1.76 逐项一致。
- 原生开门和切图已验证；素材清单缺少对应开门画面帧，网页尚未显示门的开闭动画。
- 商店图标按固定 OpenMir2 物品数据匹配；素材包未包含的物品帧使用通用物品图标。
- 未做长期运行、计时器长周期或大量在线玩家负载测试。8 个连接测试只验证握手。
- 服务端代码许可不覆盖原游戏的商业素材。来源与权利边界见 [第三方说明](../THIRD_PARTY_NOTICES.md) 和 [调研报告](SOURCE_RESEARCH.md)。
