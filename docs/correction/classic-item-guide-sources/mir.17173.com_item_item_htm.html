 蜡烛
你可以在沿街兜售的小贩以及刑场附近的独眼先生那里买到它。价格为11块金币。你可以在左手闲置的时候使用，以照亮黑暗中的事物。
火把
比蜡烛的持久性和范围更加大
金创药（小量）
你可以在金先生的药店，银杏山谷韩家的杂货店以及刑场符近的独眼先生那里买到它。恢复体力20，价格88金币。
金创药（中量）
你可以在毒蛇山谷，村庄边界，银杏山谷韩家的杂货店那里买到它。恢复体力40，价格：242金币。

超级金创药

黄色药粉 （大量）
可以削减敌人的抵抗力的超大量药粉
灰色药粉 （大量）
可以消耗敌人生命力的超大量药粉
疗伤药
能够快速恢复大量体力和魔法力的高级药水
魔法药（小量）
你可以在金先生的药店，银杏山谷韩家的杂货店以及刑场符近的独眼先生那里买到它。恢复魔力值30，价格：88金币。
魔法药（中量）
你可以在毒蛇山谷，村庄边界，银杏山谷韩家的杂货店那里买到它。恢复魔力值60，价格：242金币。
强效魔法药
　＋150MP 重量3
超级魔法药
　　重量20　可以解开成六个强效魔法药
祝福油
古老的米尔人制造了它，使用于武器的话，它将带来好运。这件幸运武器的拥有者将发挥他的最大的能力。它可以将武器的受咀咒值降低1，也可将普通武器的幸运值升到7。
太阳水
恢复魔力值40以及体力值30。没有人知道太阳神水的真正配方，也没有人知道为什么祖玛庙的小贩拥有这种太阳神水。
战**
战**是战神为了保护他后世的战士们而特制的。它可以使武器的持久性恢复为满值。方法为双击战**，它将应用于你正使用的武器。
修复油
将道具的持久性增加5。不适用于道具的特殊修理。如果你常期使用，武器的持久性值将降为0。
回城卷
这种物品可以让你瞬间转移到你最后去过的一个小镇里，当你在洞穴里或者山谷里走迷路的时候，这种物品就显得分外的重要了.不过很可惜，这种高级的物品是不能够在一般的商店里买到的，你只能在战斗中获取它.
地牢逃脱卷
当你在地牢中遇到困难的时候，它会把你随机传送到大陆的某个地方去。当然，你也可以在大部分小镇的小贩. 价格是110 金币
随机传送卷
这种卷将随机把你传送到同地图的某一个地方。有时可能你会落入一个更危险的区域，所以使用的时候请当心。
行会回城卷
如果你是一个拥有城市的行会的成员，它可以让你瞬间回到你的行会所占领的城市。不过这个物品对普通的玩家用处不大。
护身符
你可以在沿街兜售的小贩手里买到它，它是方士必备的工具，也只有拥有它，你修炼的某些道术才能起作用。它的使用次数为100次，售价：550金币。
肉
你能在死去的鹿，羊身上得到。售价因种类和品质的不同而不同。
鸡肉
你能在死去的鸡身上得到鸡肉，并可以出售给肉店。
