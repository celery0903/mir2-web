魔法技能

 

只要达到一定的级别，你就可以开始进行格斗技巧以及魔法的训练。你可以通过双击记载有这些技能（或者魔法）的书进行学习，通常，这些书可以在商店购买到，或者在与怪兽的战斗中获得。

战士(Warrior)
方士(Taoist)
魔法师(Wizard)

方士

治愈术: 根据修炼等级的不同，可以恢复自己或者他人的体力(HP). 消耗 4 点魔力(MP).
Lv.1 : 你可以在第 7 级开始修炼
Lv.2 : 你可以在第 11 级开始修炼
Lv.3 : 你可以在第 16 级开始修炼

精神力战法: : 根据修炼等级的不同，可以提高战斗时的命中率
Lv.1 : 你可以在第 9 级开始修炼.
Lv.2 : 你可以在第 13 级开始修炼.
Lv.3 : 你可以在第 19 级开始修炼.


施毒术: 根据修炼等级的不同，可以延长毒药的有效时间。
Lv.1 : 你可以在第 14 级开始修炼.
Lv.2 : 你可以在第 17 级开始修炼.
Lv.3 : 你可以在第 20 级开始修炼.

灰色毒粉
中毒的目标将会全身发绿，并且会慢慢失去它的体力。制作这种毒药,需要4片食人树的叶子，1个食人树的果实，和2颗毒蜘蛛的牙齿。每份毒粉可以使用50次。
黄色毒粉
黄色毒粉通过侵蚀目标的武器和防具来减低防御力。毒粉同时还会破坏武器和防具的耐用性。制作这种毒药，需要4片食人树的叶子，1个蝎子的尾巴，以及蛆卵。每份毒粉可以使用50次。

灵魂火符: 和火球术一样的远程法术，通过驱使护身符来攻击敌人。
Lv.1 : 你可以在第 18 级开始修炼.
Lv.2 : 你可以在第 21 级开始修炼.
Lv.3 : 你可以在第 24 级开始修炼.

召唤骷髅: 一种通过使用护身符和复活力制造骷髅的法术。制造出的骷髅将会成为你最忠诚的跟随者。这是复活术的第一步.
Lv.1 : 你可以在第 19 级开始修炼.
Lv.2 : 你可以在第 23 级开始修炼.
Lv.3 : 你可以在第 26 级开始修炼.

隐身术: 隐身术使怪物无法察觉你的存在。使用这种法术后采用魔法远程攻击，是一种非常理想的单对单战斗方法。
Lv.1 : y你可以在第 20 级开始修炼.
Lv.2 : 你可以在第 23 级开始修炼.
Lv.3 : 你可以在第 26 级开始修炼.

集体隐身术 : 更加强大的隐身术，能够隐藏3X3范围内的全体玩家。集体作战时是一种非常有用的保护措施。
Lv.1 : 你可以在第 21 级开始修炼.
Lv.2 : 你可以在第 25 级开始修炼.
Lv.3 : 你可以在第 29 级开始修炼.

幽灵盾 : 能够提高魔法防御力。他的有效时间随着训练等级的提高而延长。
Lv.1 : 你可以在第 22 级开始修炼.
Lv.2 : 你可以在第 24 级开始修炼.
Lv.3 : 你可以在第 26 级开始修炼.

神圣战甲术: 能够提高防御力。他的有效时间随着训练等级的提高，和方士的精神力(Zen Power)的高低而提高.
Lv.1 : 你可以在第 25 级开始修炼.
Lv.2 : 你可以在第 27 级开始修炼.
Lv.3 : 你可以在第 29 级开始修炼.

心灵启示: 能够展示目标（包括玩家和怪兽）体力。持续时间随等级增长。
Lv.1 : 你可以在第 26 级开始修炼.
Lv.2 : 你可以在第 30 级开始修炼.
Lv.3 : 你可以在第 35 级开始修炼.

困魔咒: 被限制在咒语中的怪兽因为看不见外面的情况只能绕着圈走。但是当你和其他人走进这个六角形的时候这个魔法会消失。当被困住的怪物受到外界攻击时能够躲避。即使你和很多人战斗的时候最好是一对一，困魔咒会发光以显示边界。
Lv.1 : 你可以在第 28 级开始修炼.
Lv.2 : 你可以在第 30 级开始修炼.
Lv.3 : 你可以在第 32 级开始修炼.

群体治愈术: 能够恢复自己和周围所有玩家的体力，治疗效果随等级增长。
Lv.1 : 你可以在第 33 级开始修炼.
Lv.2 : 你可以在第 35 级开始修炼.
Lv.3 : 你可以在第 38 级开始修炼.

召唤神兽: 能够召唤一只喷火的强大神兽作自己的随从.
Lv.1 : 你可以在第 35 级开始修炼.
Lv.2 : 你可以在第 37 级开始修炼.
Lv.3 : 你可以在第 40 级开始修炼.
